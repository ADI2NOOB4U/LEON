# Code of Conduct

LEON welcomes constructive, respectful collaboration.

Participants are expected to:

- communicate respectfully and assume good faith;
- focus criticism on code, decisions, and evidence;
- protect private information and never publish secrets or personal data;
- disclose security issues privately through the repository's security contact;
- avoid discriminatory, harassing, or threatening behavior.

Project maintainers may moderate or remove contributions that violate these expectations.
