## Review rule

The repository distinguishes between implemented controls, pilot controls, and production controls. A feature being present in a development environment is not evidence of certification, regulatory compliance, or suitability for a particular department. Deployment approval must be based on the department's own security, privacy, accessibility, records, and procurement processes.
