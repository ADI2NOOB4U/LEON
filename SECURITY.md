# Security policy

Please do not publish credentials, tokens, personal information, private workspace files, or exploitable vulnerability details in public issues.

For a security report, contact the repository owner privately through the GitHub security advisory process when enabled, or use a private maintainer contact. Include:

- affected component and version/commit;
- reproduction steps or a minimal proof of concept;
- security impact and data exposure;
- suggested mitigation, if known.

The repository's current controls and limitations are documented in [`docs/SECURITY.md`](docs/SECURITY.md). LEON is not represented as certified or compliant for government production use until the relevant deployment assessment is completed.
